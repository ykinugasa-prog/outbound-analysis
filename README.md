# アウトバウンド接続分析アプリ

## 使い方
1. Vercel にログインします。
2. このフォルダを ZIP のままアップロード、または GitHub 経由でデプロイします。
3. 発行された URL を開きます。
4. Excel ファイルをアップロードします。
5. 発信数・接続数・接続率が自動表示されます。

## データ条件
- B列：顧客 最新結果コード
- C列〜G列：発信日時
- 最大30,000行を想定
- 21時台は20時台へ加算

## 接続判定
以下を接続として扱います。
- 「通話」を含む
- 301.解約
- 6.逝去
- 305.フォロー済
- 306.変更
- 8.認知症

## セキュリティ
アップロードされたExcelはブラウザ内で処理します。サーバー保存は行いません。
